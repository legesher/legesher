## How to Read These Reports

### Report Structure

Each report contains:

1. **Executive Summary**: High-level metrics and key findings
2. **Consensus Translations**: Keywords with strong agreement across providers
3. **Conflicting Translations**: Keywords with disagreement, including recommendations
4. **Detailed Analysis**: Agreement metrics, cultural sensitivity, and quality scores
5. **Recommendations**: Action items and next steps

### Confidence Levels

Reports use a confidence scoring system:

- **100%**: Full agreement across all providers
- **90-99%**: High agreement, minor variations
- **75-89%**: Good agreement, some notable differences
- **60-74%**: Medium conflict, requires review
- **<60%**: High conflict, requires community discussion

### Conflict Classification

- **Low Conflict**: 75-89% agreement - Accept consensus translation
- **Medium Conflict**: 60-74% agreement - Community validation recommended
- **High Conflict**: <60% agreement - Extended discussion required

## Generating Your Own Reports

### Prerequisites

```bash
# Install legesher-i18n with comparison system
cd libs/i18n
uv install
```

### Basic Usage

```python
from legesher_i18n.comparison import TranslationComparator
from legesher_i18n.api.providers import AnthropicProvider, OpenAIProvider
from legesher_i18n.reports import ReportGenerator

# Initialize providers
claude = AnthropicProvider(api_key="your-api-key")
gpt4 = OpenAIProvider(api_key="your-api-key")

# Run comparison
comparator = TranslationComparator(
    providers=[claude, gpt4],
    language="es",
    python_version="3.13"
)

results = comparator.compare()

# Generate report
generator = ReportGenerator()
report = generator.generate_markdown(results)

# Save report
with open("my_comparison.md", "w") as f:
    f.write(report)
```

### CLI Usage

```bash
# Compare translations for Spanish
python -m legesher_i18n.comparison.cli compare es --providers claude,gpt4,aya23

# Generate report
python -m legesher_i18n.comparison.cli report es --output spanish_report.md

# Multi-language comparison
python -m legesher_i18n.comparison.cli compare-multi es,ar,zh --output multi_lang_summary.md
```

### Advanced Options

```bash
# Compare with custom confidence threshold
python -m legesher_i18n.comparison.cli compare es --confidence-threshold 0.8

# Include cultural analysis
python -m legesher_i18n.comparison.cli compare es --cultural-analysis

# Export to JSON for further processing
python -m legesher_i18n.comparison.cli compare es --format json --output results.json
```

## Report Templates

### Creating Custom Reports

You can customize report generation:

```python
from legesher_i18n.reports import ReportGenerator, ReportConfig

config = ReportConfig(
    include_cultural_analysis=True,
    include_provider_comparison=True,
    conflict_threshold=0.75,
    sections=[
        "executive_summary",
        "consensus_translations",
        "conflicts",
        "metrics",
        "recommendations"
    ]
)

generator = ReportGenerator(config=config)
report = generator.generate_markdown(results)
```

### Report Formats

Supported output formats:

- **Markdown** (`.md`): Human-readable reports (default)
- **JSON** (`.json`): Machine-readable data for analysis
- **HTML** (`.html`): Web-friendly reports with interactive charts
- **CSV** (`.csv`): Spreadsheet-compatible for data analysis

## Interpreting Metrics

### Agreement Score

Percentage of matching translations between providers:

```
Agreement = (Matching Translations) / (Total Translations) × 100
```

### Consensus Rate

Percentage of keywords with high agreement (90%+):

```
Consensus Rate = (High Agreement Keywords) / (Total Keywords) × 100
```

### Cultural Sensitivity Score

Manual review score (1-10) based on:
- Cultural appropriateness
- Regional awareness
- Technical context understanding
- Community feedback

### Consistency Score

How consistently a provider translates related keywords:

```
Consistency = 1 - (Variance in Related Translations) / (Expected Variance)
```

## Example Workflows

### Workflow 1: Validating a New Language Pack

```bash
# 1. Generate translations from multiple providers
python -m legesher_i18n.comparison.cli compare fr --providers all

# 2. Review consensus translations
python -m legesher_i18n.comparison.cli report fr --section consensus

# 3. Identify conflicts requiring review
python -m legesher_i18n.comparison.cli report fr --section conflicts --threshold high

# 4. Generate full report for community review
python -m legesher_i18n.comparison.cli report fr --output french_validation.md
```

### Workflow 2: Updating Existing Language Pack

```bash
# 1. Compare new AI translations with existing community pack
python -m legesher_i18n.comparison.cli compare es --include-community

# 2. Identify discrepancies
python -m legesher_i18n.comparison.cli diff es

# 3. Generate change report
python -m legesher_i18n.comparison.cli report es --output spanish_updates.md
```

### Workflow 3: Cross-Language Quality Check

```bash
# 1. Run comparison across all languages
python -m legesher_i18n.comparison.cli compare-multi es,ar,zh,fr,de,ja

# 2. Generate summary report
python -m legesher_i18n.comparison.cli report-multi --output quality_summary.md

# 3. Export metrics for analysis
python -m legesher_i18n.comparison.cli metrics --format csv --output metrics.csv
```
