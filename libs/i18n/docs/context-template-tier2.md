## Translation Validation Criteria

### For Human Reviewers & Beta Testers

**Use this checklist to evaluate a proposed translation:**

#### Concept Accuracy (CRITICAL)

- [ ] Does this translation capture what the Python term DOES?
- [ ] Would a native speaker understand its function in code?
- [ ] Does it avoid misleading connotations or wrong meanings?
- [ ] Is it technically precise?

**Test:** Show the translation to a native speaker programmer without context. Can they guess what it does?

#### Linguistic Correctness

- [ ] Is the part of speech correct (verb/noun/adjective)?
- [ ] Is the form correct (infinitive/imperative/etc.)?
- [ ] Does it follow target language grammar rules?
- [ ] Is capitalization appropriate for the language?
- [ ] For RTL languages: No unnecessary diacritics?
- [ ] For gendered languages: Consistent gender choice?

#### Consistency with Pattern

- [ ] Matches other terms in the same pattern (action keywords, state keywords, etc.)?
- [ ] Uses same verb form as similar action keywords?
- [ ] Aligns with related terms (checked cross-references)?

#### Usability

- [ ] Short enough? (1-2 words for keywords, max 3 for builtins)
- [ ] Easy to type on standard keyboard?
- [ ] Easy to pronounce?
- [ ] Easy to remember?
- [ ] Visually scannable in code?

#### Cultural Appropriateness

- [ ] No offensive meanings?
- [ ] Not childish or unprofessional?
- [ ] Respects regional sensitivities?
- [ ] Appropriate register (technical/formal, not slang)?

#### CS Education Alignment

- [ ] Matches terminology used in target language CS education?
- [ ] Checked against textbooks/tutorials in target language?
- [ ] Would students recognize this term from their classes?

#### Technical Compatibility

- [ ] Uses correct character set (Unicode block) for language?
- [ ] Will render in common fonts?
- [ ] Will display in VS Code/PyCharm/terminals?
- [ ] For RTL: Tested bidirectional text rendering?
- [ ] No special characters that break syntax highlighting?

### Severity Levels

**P0 (Blocker - Must fix):**

- Technically inaccurate (wrong concept)
- Offensive or culturally inappropriate
- Impossible to type on standard keyboard
- Doesn't render in major IDEs

**P1 (High - Should fix):**

- Inconsistent with pattern
- Awkward or unnatural phrasing
- Too long (>3 words)
- Ambiguous with other keyword

**P2 (Medium - Nice to fix):**

- Doesn't align with regional CS education
- Slightly awkward pronunciation
- Missing cognate advantage

**P3 (Low - Optional):**

- Could be shorter
- Alternative might be slightly more natural
- Minor stylistic preferences
