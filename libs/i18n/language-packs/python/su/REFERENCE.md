## Reserved Words (2 terms)

Python conventions like `self` and `cls` translated deterministically by the
language pack rather than the LLM. Distinct from keywords because they aren't
actual reserved words in the Python language. (CORE-710)

| English | Sundanese |
| ------- | ------ |
| `cls` | `kelas_sorangan` |
| `self` | `sorangan` |

## Example Code

Here's an example showing Sundanese Python code with Legesher:

```python
# Conto: Fungsi faktorial kalawan penanganan kasalahan

ti typing ngimpor Optional

fungsi faktorial(n):
    """Itung faktorial tina n."""
    lamun n < 0:
        angkat KasalahanNilai("Wilangan negatif teu diwenangkeun")
    lamun_deui n == 0 atawa n == 1:
        balikkeun 1
    lamun_henteu:
        balikkeun n * faktorial(n - 1)

fungsi utama():
    angka = [bulat(x) keur x dina rentang(6)]

    keur wilangan dina angka:
        hasil = faktorial(wilangan)
        citak(f"{wilangan}! = {hasil}")

    # Demonstrasi loop while
    cacah = 0
    salami cacah < 3:
        citak(f"Cacah: {cacah}")
        cacah += 1

    # Demonstrasi try/except
    cobaan:
        faktorial(-1)
    iwal KasalahanNilai jadi kasalahan:
        citak(f"Kasalahan: {kasalahan}")
    pamungkas:
        citak("Rengse!")

lamun __name__ == "__main__":
    utama()
```

## Usage

```python
from legesher_i18n import LanguagePackLoader

# Load Sundanese pack for Python 3.12
loader = LanguagePackLoader()
pack = loader.load("su", "python", "3.12")

# Translate code
from legesher import translate
english_code = translate(your_su_code, from_lang="su", to_lang="en")
```

## Contributing

Found a better translation? We welcome contributions from native speakers!

1. Edit `legesher_i18n_python_su/packs/<version>.yml` for the Python version where the term was introduced:
   - `3.10.yml` - Base translations (most terms)
   - `3.11.yml` - Terms added in Python 3.11 (e.g., `except*`)
   - `3.12.yml` - Terms added in Python 3.12 (e.g., `type`)
   - `3.13.yml` / `3.14.yml` - Future additions
2. Submit a pull request with your reasoning
3. Translations should be natural, commonly used in CS education, and easy to type
