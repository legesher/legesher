# legesher-i18n-python-mk

Macedonian (Македонски) language pack for Python in Legesher.

## Overview

This package provides Macedonian translations for Python keywords and built-in functions,
enabling developers to write Python code in Macedonian.

## Supported Python Versions

- Python 3.10
- Python 3.11
- Python 3.12
- Python 3.13
- Python 3.14

## Installation

```bash
uv pip install legesher-i18n legesher-i18n-python-mk
```

## Translation Coverage

- **Keywords**: 37 Python keywords
- **Built-ins**: 72 built-in functions and types
- **Exceptions**: 66 exception classes

## Version Inheritance

- `3.10.yml` - Complete Python 3.10 translations
- `3.11.yml` - Extends 3.10, adds `except*` and exception groups
- `3.12.yml` - Extends 3.11, adds `type` keyword
- `3.13.yml` - Extends 3.12
- `3.14.yml` - Extends 3.13
