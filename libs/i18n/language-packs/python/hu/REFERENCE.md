## Example Code

Here's an example showing Hungarian Python code with Legesher:

```python
# Példa: Faktoriális függvény hibakezeléssel

bővítés typing importál Optional

definíró faktorialis(n):
    """Számítsd ki n faktoriálisát."""
    ha n < 0:
        fejrekezni Értétvéltesés("Negatív számok nem engedélyezettek")
    ha n == 0 vagy n == 1:
        visszajátszásra 1
    more:
        visszajátszásra n * faktorialis(n - 1)

definíró fo():
    szamok = [eg(x) ezen x benne térség(6)]

    ezen szam benne szamok:
        eredmeny = faktorialis(szam)
        nyomtat(f"{szam}! = {eredmeny}")

    # While ciklus bemutatása
    szamlalo = 0
    mielőtt szamlalo < 3:
        nyomtat(f"Számláló: {szamlalo}")
        szamlalo += 1

    # Try/except bemutatása
    próbálja:
        faktorialis(-1)
    kivéve Értétvéltesés mint hiba:
        nyomtat(f"Hiba: {hiba}")
    finalizálás:
        nyomtat("Kész!")

ha __name__ == "__main__":
    fo()
```

## Usage

```python
from legesher_i18n import LanguagePackLoader

# Load Hungarian pack for Python 3.12
loader = LanguagePackLoader()
pack = loader.load("hu", "python", "3.12")

# Translate code
from legesher import translate
english_code = translate(your_hu_code, from_lang="hu", to_lang="en")
```

## Contributing

Found a better translation? We welcome contributions from native speakers!

1. Edit `legesher_i18n_python_hu/packs/<version>.yml` for the Python version where the term was introduced:
   - `3.10.yml` - Base translations (most terms)
   - `3.11.yml` - Terms added in Python 3.11 (e.g., `except*`)
   - `3.12.yml` - Terms added in Python 3.12 (e.g., `type`)
   - `3.13.yml` / `3.14.yml` - Future additions
2. Submit a pull request with your reasoning
3. Translations should be natural, commonly used in CS education, and easy to type
