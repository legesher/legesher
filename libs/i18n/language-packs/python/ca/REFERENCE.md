## Reserved Words (2 terms)

Python conventions like `self` and `cls` translated deterministically by the
language pack rather than the LLM. Distinct from keywords because they aren't
actual keywords in the Python language. (CORE-710)

| `self` | `mateix` |

## Example Code

Here's an example showing Catalan Python code with Legesher:

```python
# Exemple: Funció factorial amb gestió d'errors

de typing importar Optional

definir factorial(n):
    """Calcula el factorial de n."""
    si n < 0:
        llençar errorvalor("Els nombres negatius no estan permesos")
    sinosi n == 0 o n == 1:
        retornar 1
    sino:
        retornar n * factorial(n - 1)

definir principal():
    nombres = [enter(x) per x en rang(6)]

    per nombre en nombres:
        resultat = factorial(nombre)
        imprimir(f"{nombre}! = {resultat}")

    # Demostració del bucle while
    comptador = 0
    mentre comptador < 3:
        imprimir(f"Comptador: {comptador}")
        comptador += 1

    # Demostració de try/except
    intentar:
        factorial(-1)
    excepte errorvalor com error:
        imprimir(f"Error: {error}")
    finalment:
        imprimir("Fet!")

si __name__ == "__main__":
    principal()
```

## Usage

```python
from legesher_i18n import LanguagePackLoader

# Load Catalan pack for Python 3.12
loader = LanguagePackLoader()
pack = loader.load("ca", "python", "3.12")

# Translate code
from legesher import translate
english_code = translate(your_ca_code, from_lang="ca", to_lang="en")
```

## Contributing

Found a better translation? We welcome contributions from native speakers!

1. Edit `legesher_i18n_python_ca/packs/<version>.yml` for the Python version where the term was introduced:
   - `3.10.yml` - Base translations (most terms)
   - `3.11.yml` - Terms added in Python 3.11 (e.g., `except*`)
   - `3.12.yml` - Terms added in Python 3.12 (e.g., `type`)
   - `3.13.yml` / `3.14.yml` - Future additions
2. Submit a pull request with your reasoning
3. Translations should be natural, commonly used in CS education, and easy to type
