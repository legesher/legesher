## Reserved Words (2 terms)

Python conventions like `self` and `cls` translated deterministically by the
language pack rather than the LLM. Distinct from keywords because they aren't
actual reserved words in the Python language. (CORE-710)

| English | Dutch |
| ------- | ------ |
| `cls` | `eigenklasse` |
| `self` | `zichzelf` |

## Example Code

Here's an example showing Dutch Python code with Legesher:

```python
# Voorbeeld: Faculteitsfunctie met foutafhandeling

van typing importeren Optional

definitie faculteit(n):
    """Bereken de faculteit van n."""
    indien n < 0:
        opheffen Waardefout("Negatieve getallen zijn niet toegestaan")
    alswel n == 0 of n == 1:
        teruggeven 1
    anders:
        teruggeven n * faculteit(n - 1)

definitie hoofd():
    getallen = [geheel_getal(x) voor x bevat bereik(6)]

    voor getal bevat getallen:
        resultaat = faculteit(getal)
        afdrukken(f"{getal}! = {resultaat}")

    # Demonstreer while-lus
    teller = 0
    terwijl teller < 3:
        afdrukken(f"Teller: {teller}")
        teller += 1

    # Demonstreer try/except
    proberen:
        faculteit(-1)
    behalve Waardefout als fout:
        afdrukken(f"Fout: {fout}")
    tenslotte:
        afdrukken("Klaar!")

indien __name__ == "__main__":
    hoofd()
```

## Usage

```python
from legesher_i18n import LanguagePackLoader

# Load Dutch pack for Python 3.12
loader = LanguagePackLoader()
pack = loader.load("nl", "python", "3.12")

# Translate code
from legesher import translate
english_code = translate(your_nl_code, from_lang="nl", to_lang="en")
```

## Contributing

Found a better translation? We welcome contributions from native speakers!

1. Edit `legesher_i18n_python_nl/packs/<version>.yml` for the Python version where the term was introduced:
   - `3.10.yml` - Base translations (most terms)
   - `3.11.yml` - Terms added in Python 3.11 (e.g., `except*`)
   - `3.12.yml` - Terms added in Python 3.12 (e.g., `type`)
   - `3.13.yml` / `3.14.yml` - Future additions
2. Submit a pull request with your reasoning
3. Translations should be natural, commonly used in CS education, and easy to type
