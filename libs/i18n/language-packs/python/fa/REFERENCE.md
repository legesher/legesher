## Reserved Words (2 terms)

Python conventions like `self` and `cls` translated deterministically by the
language pack rather than the LLM. Distinct from keywords because they aren't
actual keywords in the Python language. (CORE-710)

| English | Persian |
| ------- | ------ |
| `cls` | `خودکلاس` |
| `self` | `خود` |

## Example Code

Here's an example showing Persian Python code with Legesher:

```python
# مثال: تابع فاکتوریل با مدیریت خطا

از typing واردکردن Optional

تعریف فاکتوریل(n):
    """محاسبه فاکتوریل n."""
    اگر n < 0:
        بالاانداختن خطایمقدار("اعداد منفی مجاز نیستند")
    واگرنه n == 0 یا n == 1:
        بازگشت 1
    درغیراینصورت:
        بازگشت n * فاکتوریل(n - 1)

تعریف اصلی():
    اعداد = [صحیح(x) برای x در بازه(6)]

    برای عدد در اعداد:
        نتیجه = فاکتوریل(عدد)
        چاپ(f"{عدد}! = {نتیجه}")

    # نمایش حلقه while
    شمارنده = 0
    تاوقتیکه شمارنده < 3:
        چاپ(f"شمارنده: {شمارنده}")
        شمارنده += 1

    # نمایش try/except
    تلاش:
        فاکتوریل(-1)
    بجز خطایمقدار بعنوان خطا:
        چاپ(f"خطا: {خطا}")
    درنهایت:
        چاپ("تمام!")

اگر __name__ == "__main__":
    اصلی()
```

## Usage

```python
from legesher_i18n import LanguagePackLoader

# Load Persian pack for Python 3.12
loader = LanguagePackLoader()
pack = loader.load("fa", "python", "3.12")

# Translate code
from legesher import translate
english_code = translate(your_fa_code, from_lang="fa", to_lang="en")
```

## Contributing

Found a better translation? We welcome contributions from native speakers!

1. Edit `legesher_i18n_python_fa/packs/<version>.yml` for the Python version where the term was introduced:
   - `3.10.yml` - Base translations (most terms)
   - `3.11.yml` - Terms added in Python 3.11 (e.g., `except*`)
   - `3.12.yml` - Terms added in Python 3.12 (e.g., `type`)
   - `3.13.yml` / `3.14.yml` - Future additions
2. Submit a pull request with your reasoning
3. Translations should be natural, commonly used in CS education, and easy to type
