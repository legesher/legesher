## Reserved Words (2 terms)

Python conventions like `self` and `cls` translated deterministically by the
language pack rather than the LLM. Distinct from keywords because they aren't
actual keywords in the Python language. (CORE-710)

| English | Xhosa |
| ------- | ------ |
| `cls` | `udidilwayo` |
| `self` | `isiqu` |

## Example Code

Here's an example showing Xhosa Python code with Legesher:

```python
# Umzekelo: ifaktoriyali kunye nokulawula iimpazamo

ukusuka typing ngenisa Optional

chaza ifaktoriyali(n):
    """Bala ifaktoriyali ka-n."""
    ukuba n < 0:
        phakamisa impazamoyexabiso("Amanani angaphantsi kweqanda awavumelekanga")
    kungenjaloukuba n == 0 okanye n == 1:
        buyisa 1
    kungenjalo:
        buyisa n * ifaktoriyali(n - 1)

chaza eyona():
    amanani = [inanielipheleleyo(x) nganye x phakathi uthotho(6)]

    nganye inani phakathi amanani:
        isiphumo = ifaktoriyali(inani)
        shicilela(f"{inani}! = {isiphumo}")

    # Umboniso we-while
    isibali = 0
    ngelixa isibali < 3:
        shicilela(f"Isibali: {isibali}")
        isibali += 1

    # Umboniso we-try/except
    zama:
        ifaktoriyali(-1)
    ngaphandle impazamoyexabiso njenga impazamo:
        shicilela(f"Impazamo: {impazamo}")
    ekugqibeleni:
        shicilela("Kugqityiwe!")

ukuba __name__ == "__main__":
    eyona()
```

## Usage

```python
from legesher_i18n import LanguagePackLoader

# Load Xhosa pack for Python 3.12
loader = LanguagePackLoader()
pack = loader.load("xh", "python", "3.12")

# Translate code
from legesher import translate
english_code = translate(your_xh_code, from_lang="xh", to_lang="en")
```

## Contributing

Found a better translation? We welcome contributions from native speakers!

1. Edit `legesher_i18n_python_xh/packs/<version>.yml` for the Python version where the term was introduced:
   - `3.10.yml` - Base translations (most terms)
   - `3.11.yml` - Terms added in Python 3.11 (e.g., `except*`)
   - `3.12.yml` - Terms added in Python 3.12 (e.g., `type`)
   - `3.13.yml` / `3.14.yml` - Future additions
2. Submit a pull request with your reasoning
3. Translations should be natural, commonly used in CS education, and easy to type
