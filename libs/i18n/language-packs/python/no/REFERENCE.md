## Example Code

Here's an example showing Norwegian Python code with Legesher:

```python
# Eksempel: Fakultetsfunksjon med feilhåndtering

fra typing importere Optional

definisjon fakultet(n):
    """Beregn fakultet av n."""
    om n < 0:
        oppnå Værdfeil("Negative tall er ikke tillatt")
    elsif n == 0 eller n == 1:
        retur 1
    annett:
        retur n * fakultet(n - 1)

definisjon hoved():
    tall = [ent(x) for x in område(6)]

    for nummer in tall:
        resultat = fakultet(nummer)
        print(f"{nummer}! = {resultat}")

    # Demonstrer while-løkke
    teller = 0
    while teller < 3:
        print(f"Teller: {teller}")
        teller += 1

    # Demonstrer try/except
    prøve:
        fakultet(-1)
    except Værdfeil as feil:
        print(f"Feil: {feil}")
    forrestil:
        print("Ferdig!")

om __name__ == "__main__":
    hoved()
```

## Usage

```python
from legesher_i18n import LanguagePackLoader

# Load Norwegian pack for Python 3.12
loader = LanguagePackLoader()
pack = loader.load("no", "python", "3.12")

# Translate code
from legesher import translate
english_code = translate(your_no_code, from_lang="no", to_lang="en")
```

## Contributing

Found a better translation? We welcome contributions from native speakers!

1. Edit `legesher_i18n_python_no/packs/<version>.yml` for the Python version where the term was introduced:
   - `3.10.yml` - Base translations (most terms)
   - `3.11.yml` - Terms added in Python 3.11 (e.g., `except*`)
   - `3.12.yml` - Terms added in Python 3.12 (e.g., `type`)
   - `3.13.yml` / `3.14.yml` - Future additions
2. Submit a pull request with your reasoning
3. Translations should be natural, commonly used in CS education, and easy to type
