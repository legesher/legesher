## Example Code

Here's an example showing Malayalam Python code with Legesher:

```python
# ഉദാഹരണം: പിശക് കൈകാര്യം ചെയ്യലോടെ ഫാക്ടോറിയൽ ഫങ്ഷൻ

ഇൽനിന്ന് typing ഇറക്കുമതി Optional

നിർവചനം ഫാക്ടോറിയൽ(n):
    """n ന്റെ ഫാക്ടോറിയൽ കണക്കാക്കുക."""
    എങ്കിൽ n < 0:
        ഉയർത്തുക മൂല്യപിശക്("ഋണ സംഖ്യകൾ അനുവദനീയമല്ല")
    അല്ലെങ്കിൽ_എങ്കിൽ n == 0 അഥവാ n == 1:
        മടക്കുക 1
    അല്ലെങ്കിൽ:
        മടക്കുക n * ഫാക്ടോറിയൽ(n - 1)

നിർവചനം പ്രധാന():
    സംഖ്യകൾ = [പൂർണ്ണസംഖ്യ(x) വേണ്ടി x ഉള്ളിൽ പരിധി(6)]

    വേണ്ടി സംഖ്യ ഉള്ളിൽ സംഖ്യകൾ:
        ഫലം = ഫാക്ടോറിയൽ(സംഖ്യ)
        അച്ചടിക്കുക(f"{സംഖ്യ}! = {ഫലം}")

    # while ലൂപ്പ് പ്രദർശനം
    എണ്ണം = 0
    ആയിരിക്കുമ്പോൾ എണ്ണം < 3:
        അച്ചടിക്കുക(f"എണ്ണം: {എണ്ണം}")
        എണ്ണം += 1

    # try/except പ്രദർശനം
    ശ്രമിക്കുക:
        ഫാക്ടോറിയൽ(-1)
    ഒഴികെ മൂല്യപിശക് ആയി പിശക്:
        അച്ചടിക്കുക(f"പിശക്: {പിശക്}")
    ഒടുവിൽ:
        അച്ചടിക്കുക("പൂർത്തിയായി!")

എങ്കിൽ __name__ == "__main__":
    പ്രധാന()
```
