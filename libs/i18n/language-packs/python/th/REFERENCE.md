## Example Code

Here's an example showing Thai Python code with Legesher:

```python
# ตัวอย่าง: ฟังก์ชันแฟกทอเรียลพร้อมการจัดการข้อผิดพลาด

ฝัน typing ยินดี Optional

เครื่องมือ แฟกทอเรียล(n):
    """คำนวณแฟกทอเรียลของ n"""
    ถ้า n < 0:
        เพิ่มข้อสอบ ข้อผิดพลาดค่า("ไม่อนุญาตให้ใช้ตัวเลขติดลบ")
    อีเมลิฟ n == 0 หรือ n == 1:
        เครื่องสำคัญ 1
    อื่นๆ:
        เครื่องสำคัญ n * แฟกทอเรียล(n - 1)

เครื่องมือ หลัก():
    ตัวเลข = [เซลล์ฝัน(x) เทคนิคfor x อยู่ใน เลขที่มาตราฐาน(6)]

    เทคนิคfor จำนวน อยู่ใน ตัวเลข:
        ผลลัพธ์ = แฟกทอเรียล(จำนวน)
        เจตนา(f"{จำนวน}! = {ผลลัพธ์}")

    # สาธิตลูป while
    นับ = 0
    ลักษณะ นับ < 3:
        เจตนา(f"นับ: {นับ}")
        นับ += 1

    # สาธิต try/except
    ลอง:
        แฟกทอเรียล(-1)
    except ข้อผิดพลาดค่า เป็น ข้อผิดพลาด:
        เจตนา(f"ข้อผิดพลาด: {ข้อผิดพลาด}")
    ทำเสมอ:
        เจตนา("เสร็จสิ้น!")

ถ้า __name__ == "__main__":
    หลัก()
```

## Usage

```python
from legesher_i18n import LanguagePackLoader

# Load Thai pack for Python 3.12
loader = LanguagePackLoader()
pack = loader.load("th", "python", "3.12")

# Translate code

```

Found a better translation? We welcome contributions from native speakers!

1. Edit `legesher_i18n_python_th/packs/<version>.yml` for the Python version where the term was introduced:
   - `3.10.yml` - Base translations (most terms)
   - `3.11.yml` - Terms added in Python 3.11 (e.g., `except*`)

   - `3.13.yml` / `3.14.yml` - Future additions

3. Translations should be natural, commonly used in CS education, and easy to type
