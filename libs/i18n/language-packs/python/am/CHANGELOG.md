# Changelog

All notable changes to the Amharic language pack will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.0.2] - 2026-04-29

### Added

- `self` and `cls` reserved word translations [CORE-710]

## [0.0.1] - 2026-03-10

### Added

- Initial Amharic language pack for Python 3.10-3.14 (CORE-690)
- 39 keyword translations using Ge'ez script
- 72 built-in function and type translations
- 69 exception class translations
- Version inheritance chain (3.10 -> 3.11 -> 3.12 -> 3.13 -> 3.14)
- Translation Source: Claude AI Model
