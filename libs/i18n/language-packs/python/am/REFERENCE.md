## Reserved Words (2 terms)

Python conventions like `self` and `cls` translated deterministically by the
language pack rather than the LLM. Distinct from keywords because they aren't
actual keywords in the Python language. (CORE-710)

| English | Amharic |
| ------- | ------ |
| `cls` | `ክፍልራስ` |
| `self` | `ራስ` |

## Example Code

Here's an example showing Amharic Python code with Legesher:

```python
# ምሳሌ፡ ከስህተት አያያዝ ጋር ፋክቶሪያል ተግባር

ከ typing አስመጣ Optional

ግለጽ ፋክቶሪያል(n):
    """የን ፋክቶሪያል ያስላል።"""
    ከሆነ n < 0:
        አንሳ የእሴትስህተት("አሉታዊ ቁጥሮች አይፈቀዱም")
    ካልሆነ n == 0 ወይም n == 1:
        መልስ 1
    ያለበለዚያ:
        መልስ n * ፋክቶሪያል(n - 1)

ግለጽ ዋና():
    ቁጥሮች = [ኢንቲጀር(x) ለእያንዳንዱ x ውስጥ ክልል(6)]

    ለእያንዳንዱ ቁጥር ውስጥ ቁጥሮች:
        ውጤት = ፋክቶሪያል(ቁጥር)
        አትም(f"{ቁጥር}! = {ውጤት}")

    # የእስከ ዙር ማሳያ
    ቆጠራ = 0
    እስከ ቆጠራ < 3:
        አትም(f"ቆጠራ: {ቆጠራ}")
        ቆጠራ += 1

    # የሞክር/ከቀረ ማሳያ
    ሞክር:
        ፋክቶሪያል(-1)
    ከቀረ የእሴትስህተት እንደ ስህተት:
        አትም(f"ስህተት: {ስህተት}")
    በመጨረሻ:
        አትም("ተጠናቋል!")

ከሆነ __name__ == "__main__":
    ዋና()
```

## Usage

```python
from legesher_i18n import LanguagePackLoader

# Load Amharic pack for Python 3.12
loader = LanguagePackLoader()
pack = loader.load("am", "python", "3.12")

# Translate code
from legesher import translate
english_code = translate(your_am_code, from_lang="am", to_lang="en")
```

## Contributing

Found a better translation? We welcome contributions from native speakers!

1. Edit `legesher_i18n_python_am/packs/<version>.yml` for the Python version where the term was introduced:
   - `3.10.yml` - Base translations (most terms)
   - `3.11.yml` - Terms added in Python 3.11 (e.g., `except*`)
   - `3.12.yml` - Terms added in Python 3.12 (e.g., `type`)
   - `3.13.yml` / `3.14.yml` - Future additions
2. Submit a pull request with your reasoning
3. Translations should be natural, commonly used in CS education, and easy to type
