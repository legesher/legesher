## Reserved Words (2 terms)

Python conventions like `self` and `cls` translated deterministically by the
language pack rather than the LLM. Distinct from keywords because they aren't
actual reserved words in the Python language. (CORE-710)

| English | Malay |
| ------- | ------ |
| `cls` | `kelasdiri` |
| `self` | `diri` |

## Example Code

Here's an example showing Malay Python code with Legesher:

```python
# Contoh: Fungsi faktorial dengan pengendalian ralat

dari typing mengimpor Optional

menentukan faktorial(n):
    """Kira faktorial n."""
    jika n < 0:
        menciptakan Kesalahannilai("Nombor negatif tidak dibenarkan")
    lainjika n == 0 atau n == 1:
        kembali 1
    lainnya:
        kembali n * faktorial(n - 1)

menentukan utama():
    nombor = [integer(x) untuk x dalam jangk(6)]

    untuk nom dalam nombor:
        hasil = faktorial(nom)
        cetak(f"{nom}! = {hasil}")

    # Tunjukkan gelung while
    kiraan = 0
    sambil kiraan < 3:
        cetak(f"Kiraan: {kiraan}")
        kiraan += 1

    # Tunjukkan try/except
    coba:
        faktorial(-1)
    kecuali Kesalahannilai sebagai ralat:
        cetak(f"Ralat: {ralat}")
    akhirnya:
        cetak("Selesai!")

jika __name__ == "__main__":
    utama()
```

## Usage

```python
from legesher_i18n import LanguagePackLoader

# Load Malay pack for Python 3.12
loader = LanguagePackLoader()
pack = loader.load("ms", "python", "3.12")

# Translate code
from legesher import translate
english_code = translate(your_ms_code, from_lang="ms", to_lang="en")
```

## Contributing

Found a better translation? We welcome contributions from native speakers!

1. Edit `legesher_i18n_python_ms/packs/<version>.yml` for the Python version where the term was introduced:
   - `3.10.yml` - Base translations (most terms)
   - `3.11.yml` - Terms added in Python 3.11 (e.g., `except*`)
   - `3.12.yml` - Terms added in Python 3.12 (e.g., `type`)
   - `3.13.yml` / `3.14.yml` - Future additions
2. Submit a pull request with your reasoning
3. Translations should be natural, commonly used in CS education, and easy to type
