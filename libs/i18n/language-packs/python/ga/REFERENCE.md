## Example Code

Here's an example showing Irish Python code with Legesher:

```python
# Sampla: Feidhm fachtóirigh le láimhseáil earráidí

ó typing iompórtáil Optional

sainmhínigh fachtóireach(n):
    """Ríomh fachtóireach n."""
    má n < 0:
        ardaigh EarráidLuacha("Ní cheadaítear uimhreacha diúltacha")
    eileámá n == 0 nó n == 1:
        aisfhill 1
    eile:
        aisfhill n * fachtóireach(n - 1)

sainmhínigh príomh():
    uimhreacha = [slánuimhir(x) do x i raon(6)]

    do uimhir i uimhreacha:
        toradh = fachtóireach(uimhir)
        priontáil(f"{uimhir}! = {toradh}")

    # Léiriú lúb while
    áireamh = 0
    fad áireamh < 3:
        priontáil(f"Áireamh: {áireamh}")
        áireamh += 1

    # Léiriú try/except
    triail:
        fachtóireach(-1)
    seachas EarráidLuacha mar earráid:
        priontáil(f"Earráid: {earráid}")
    faoidheireadh:
        priontáil("Críochnaithe!")

má __name__ == "__main__":
    príomh()
```

## Usage

```python
from legesher_i18n import LanguagePackLoader

# Load Irish pack for Python 3.12
loader = LanguagePackLoader()
pack = loader.load("ga", "python", "3.12")

# Translate code
from legesher import translate
english_code = translate(your_ga_code, from_lang="ga", to_lang="en")
```

## Contributing

Found a better translation? We welcome contributions from native speakers!

1. Edit `legesher_i18n_python_ga/packs/<version>.yml` for the Python version where the term was introduced:
   - `3.10.yml` - Base translations (most terms)
   - `3.11.yml` - Terms added in Python 3.11 (e.g., `except*`)
   - `3.12.yml` - Terms added in Python 3.12 (e.g., `type`)
   - `3.13.yml` / `3.14.yml` - Future additions
2. Submit a pull request with your reasoning
3. Translations should be natural, commonly used in CS education, and easy to type
