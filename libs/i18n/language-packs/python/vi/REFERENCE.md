## Reserved Words (2 terms)

Python conventions like `self` and `cls` translated deterministically by the
language pack rather than the LLM. Distinct from keywords because they aren't
actual reserved words in the Python language. (CORE-710)

| English | Vietnamese |
| ------- | ------ |
| `cls` | `lớpbảnthân` |
| `self` | `bảnthân` |

## Example Code

Here's an example showing Vietnamese Python code with Legesher:

```python
# Ví dụ: Hàm giai thừa với xử lý lỗi

từ typing nhập Optional

bằng giaithua(n):
    """Tính giai thừa của n."""
    nếu n < 0:
        nângcao LỗiGiátrị("Không cho phép số âm")
    nếu_khác n == 0 hoặc n == 1:
        trảvề 1
    khác:
        trảvề n * giaithua(n - 1)

bằng chinh():
    cacso = [sốnguyên(x) cho x trong phạmvi(6)]

    cho so trong cacso:
        ketqua = giaithua(so)
        in(f"{so}! = {ketqua}")

    # Minh họa vòng lặp while
    dem = 0
    trongkhi dem < 3:
        in(f"Đếm: {dem}")
        dem += 1

    # Minh họa try/except
    thử:
        giaithua(-1)
    trừ LỗiGiátrị như loi:
        in(f"Lỗi: {loi}")
    Cuốicùng:
        in("Hoàn thành!")

nếu __name__ == "__main__":
    chinh()
```

## Usage

```python
from legesher_i18n import LanguagePackLoader

# Load Vietnamese pack for Python 3.12
loader = LanguagePackLoader()
pack = loader.load("vi", "python", "3.12")

# Translate code
from legesher import translate
english_code = translate(your_vi_code, from_lang="vi", to_lang="en")
```

## Contributing

Found a better translation? We welcome contributions from native speakers!

1. Edit `legesher_i18n_python_vi/packs/<version>.yml` for the Python version where the term was introduced:
   - `3.10.yml` - Base translations (most terms)
   - `3.11.yml` - Terms added in Python 3.11 (e.g., `except*`)
   - `3.12.yml` - Terms added in Python 3.12 (e.g., `type`)
   - `3.13.yml` / `3.14.yml` - Future additions
2. Submit a pull request with your reasoning
3. Translations should be natural, commonly used in CS education, and easy to type
