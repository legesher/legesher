actual reserved words in the Python language. (CORE-710)

## Example Code

Here's an example showing Latvian Python code with Legesher:

```python
# Piemērs: Faktoriāla funkcija ar kļūdu apstrādi

no typing importēt Optional

definēt faktorials(n):
    """Aprēķināt n faktoriālu."""
    ja n < 0:
        izsaukt VērtībasKļūda("Negatīvi skaitļi nav atļauti")
    citādiJa n == 0 vai n == 1:
        atgriezt 1
    citādi:
        atgriezt n * faktorials(n - 1)

definēt galvenais():
    skaitli = [veselaisSkaitlis(x) katram x iekš diapazons(6)]

    katram skaitlis iekš skaitli:
        rezultats = faktorials(skaitlis)
        drukāt(f"{skaitlis}! = {rezultats}")

    # while cilpas demonstrācija
    skaititajs = 0
    kamēr skaititajs < 3:
        drukāt(f"Skaitītājs: {skaititajs}")
        skaititajs += 1

    # try/except demonstrācija
    mēģināt:
        faktorials(-1)
    izņemot VērtībasKļūda kā kluda:
        drukāt(f"Kļūda: {kluda}")
    visbeidzot:
        drukāt("Gatavs!")

ja __name__ == "__main__":
    galvenais()
```

## Usage

```python
from legesher_i18n import LanguagePackLoader

# Load Latvian pack for Python 3.12
loader = LanguagePackLoader()
pack = loader.load("lv", "python", "3.12")

# Translate code
from legesher import translate
english_code = translate(your_lv_code, from_lang="lv", to_lang="en")
```

## Contributing

Found a better translation? We welcome contributions from native speakers!

1. Edit `legesher_i18n_python_lv/packs/<version>.yml` for the Python version where the term was introduced:
   - `3.10.yml` - Base translations (most terms)
   - `3.11.yml` - Terms added in Python 3.11 (e.g., `except*`)
   - `3.12.yml` - Terms added in Python 3.12 (e.g., `type`)
   - `3.13.yml` / `3.14.yml` - Future additions
2. Submit a pull request with your reasoning
3. Translations should be natural, commonly used in CS education, and easy to type
