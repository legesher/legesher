## Reserved Words (2 terms)

Python conventions like `self` and `cls` translated deterministically by the
language pack rather than the LLM. Distinct from keywords because they aren't
actual keywords in the Python language. (CORE-710)

| English | Nepali |
| ------- | ------ |
| `cls` | `आफ्नोवर्ग` |
| `self` | `स्वयं` |

## Example Code

Here's an example showing Nepali Python code with Legesher:

```python
# उदाहरण: त्रुटि व्यवस्थापनसहित क्रमगुणन

बाट typing आयातगर्नु Optional

परिभाषितगर्नु क्रमगुणन(n):
    """n को क्रमगुणन गणना गर्नुहोस्।"""
    यदि n < 0:
        उठाउनु मानत्रुटि("ऋणात्मक संख्याहरूको अनुमति छैन")
    अन्यथायदि n == 0 वा n == 1:
        फर्काउनु 1
    अन्यथा:
        फर्काउनु n * क्रमगुणन(n - 1)

परिभाषितगर्नु मुख्य():
    संख्याहरू = [पूर्णाङ्क(x) प्रत्येक x भित्र दायरा(6)]

    प्रत्येक संख्या भित्र संख्याहरू:
        नतिजा = क्रमगुणन(संख्या)
        छाप्नु(f"{संख्या}! = {नतिजा}")

    # while लुपको प्रदर्शन
    गणना = 0
    जबसम्म गणना < 3:
        छाप्नु(f"गणना: {गणना}")
        गणना += 1

    # try/except को प्रदर्शन
    प्रयासगर्नु:
        क्रमगुणन(-1)
    बाहेक मानत्रुटि रूपमा त्रुटि:
        छाप्नु(f"त्रुटि: {त्रुटि}")
    अन्तमा:
        छाप्नु("सम्पन्न!")

यदि __name__ == "__main__":
    मुख्य()
```

## Usage

```python
from legesher_i18n import LanguagePackLoader

# Load Nepali pack for Python 3.12
loader = LanguagePackLoader()
pack = loader.load("ne", "python", "3.12")

# Translate code
from legesher import translate
english_code = translate(your_ne_code, from_lang="ne", to_lang="en")
```

## Contributing

Found a better translation? We welcome contributions from native speakers!

1. Edit `legesher_i18n_python_ne/packs/<version>.yml` for the Python version where the term was introduced:
   - `3.10.yml` - Base translations (most terms)
   - `3.11.yml` - Terms added in Python 3.11 (e.g., `except*`)
   - `3.12.yml` - Terms added in Python 3.12 (e.g., `type`)
   - `3.13.yml` / `3.14.yml` - Future additions
2. Submit a pull request with your reasoning
3. Translations should be natural, commonly used in CS education, and easy to type
