## Reserved Words (2 terms)

Python conventions like `self` and `cls` translated deterministically by the
language pack rather than the LLM. Distinct from keywords because they aren't
actual keywords in the Python language. (CORE-710)

| English | Serbian |
| ------- | ------ |
| `cls` | `самакласа` |
| `self` | `себе` |

## Example Code

Here's an example showing Serbian Python code with Legesher:

```python
# Пример: Функција факторијела са обрадом грешака

из typing увези Optional

дефиниши факторијел(n):
    """Израчунај факторијел броја n."""
    ако n < 0:
        подигни ГрешкаВредности("Негативни бројеви нису дозвољени")
    инакоАко n == 0 или n == 1:
        врати 1
    иначе:
        врати n * факторијел(n - 1)

дефиниши главна():
    бројеви = [целобројни(x) за x у опсег(6)]

    за број у бројеви:
        резултат = факторијел(број)
        испиши(f"{број}! = {резултат}")

    # Демонстрација while петље
    бројач = 0
    док бројач < 3:
        испиши(f"Бројач: {бројач}")
        бројач += 1

    # Демонстрација try/except
    покушај:
        факторијел(-1)
    осим ГрешкаВредности као грешка:
        испиши(f"Грешка: {грешка}")
    коначно:
        испиши("Готово!")

ако __name__ == "__main__":
    главна()
```

## Usage

```python
from legesher_i18n import LanguagePackLoader

# Load Serbian pack for Python 3.12
loader = LanguagePackLoader()
pack = loader.load("sr", "python", "3.12")

# Translate code
from legesher import translate
english_code = translate(your_sr_code, from_lang="sr", to_lang="en")
```

## Contributing

Found a better translation? We welcome contributions from native speakers!

1. Edit `legesher_i18n_python_sr/packs/<version>.yml` for the Python version where the term was introduced:
   - `3.10.yml` - Base translations (most terms)
   - `3.11.yml` - Terms added in Python 3.11 (e.g., `except*`)
   - `3.12.yml` - Terms added in Python 3.12 (e.g., `type`)
   - `3.13.yml` / `3.14.yml` - Future additions
2. Submit a pull request with your reasoning
3. Translations should be natural, commonly used in CS education, and easy to type
