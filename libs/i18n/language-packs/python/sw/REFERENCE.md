## Reserved Words (2 terms)

Python conventions like `self` and `cls` translated deterministically by the
language pack rather than the LLM. Distinct from keywords because they aren't
actual keywords in the Python language. (CORE-710)

| English | Swahili |
| ------- | ------ |
| `cls` | `darasalake` |
| `self` | `nafsi` |

## Example Code

Here's an example showing Swahili Python code with Legesher:

```python
# Mfano: faktoria pamoja na kushughulikia hitilafu

kutoka typing agiza Optional

fasili faktoria(n):
    """Kokotoa faktoria ya namba n."""
    ikiwa n < 0:
        ibua hitilafuyathamani("Namba hasi haziruhusiwi")
    vinginevyoikiwa n == 0 au n == 1:
        rudisha 1
    vinginevyo:
        rudisha n * faktoria(n - 1)

fasili kuu():
    namba_zote = [nambakamili(x) kwa x katika masafa(6)]

    kwa namba katika namba_zote:
        matokeo = faktoria(namba)
        chapisha(f"{namba}! = {matokeo}")

    # Onyesho la kitanzi cha while
    kihesabu = 0
    wakati kihesabu < 3:
        chapisha(f"Hesabu: {kihesabu}")
        kihesabu += 1

    # Onyesho la try/except
    jaribu:
        faktoria(-1)
    isipokuwa hitilafuyathamani kama hitilafu:
        chapisha(f"Hitilafu: {hitilafu}")
    mwishowe:
        chapisha("Imekamilika!")

ikiwa __name__ == "__main__":
    kuu()
```

## Usage

```python
from legesher_i18n import LanguagePackLoader

# Load Swahili pack for Python 3.12
loader = LanguagePackLoader()
pack = loader.load("sw", "python", "3.12")

# Translate code
from legesher import translate
english_code = translate(your_sw_code, from_lang="sw", to_lang="en")
```

## Contributing

Found a better translation? We welcome contributions from native speakers!

1. Edit `legesher_i18n_python_sw/packs/<version>.yml` for the Python version where the term was introduced:
   - `3.10.yml` - Base translations (most terms)
   - `3.11.yml` - Terms added in Python 3.11 (e.g., `except*`)
   - `3.12.yml` - Terms added in Python 3.12 (e.g., `type`)
   - `3.13.yml` / `3.14.yml` - Future additions
2. Submit a pull request with your reasoning
3. Translations should be natural, commonly used in CS education, and easy to type
