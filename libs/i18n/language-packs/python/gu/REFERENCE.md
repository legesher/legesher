## Reserved Words (2 terms)

Python conventions like `self` and `cls` translated deterministically by the
language pack rather than the LLM. Distinct from keywords because they aren't
actual reserved words in the Python language. (CORE-710)

| English | Gujarati |
| ------- | ------ |
| `cls` | `સ્વવર્ગ` |
| `self` | `પોતે` |

## Example Code

Here's an example showing Gujarati Python code with Legesher:

```python
# ઉદાહરણ: ભૂલ વ્યવસ્થાપન સાથે ક્રમગુણિત ફંક્શન

માંથી typing આયાત Optional

વ્યાખ્યા ક્રમગુણિત(n):
    """n નું ક્રમગુણિત ગણો."""
    જો n < 0:
        ઉઠાવો મૂલ્યભૂલ("ઋણ સંખ્યાઓ મંજૂર નથી")
    નહીંતોજો n == 0 અથવા n == 1:
        પાછુંઆપો 1
    નહીંતો:
        પાછુંઆપો n * ક્રમગુણિત(n - 1)

વ્યાખ્યા મુખ્ય():
    સંખ્યાઓ = [પૂર્ણાંક(x) માટે x માં શ્રેણી(6)]

    માટે સંખ્યા માં સંખ્યાઓ:
        પરિણામ = ક્રમગુણિત(સંખ્યા)
        છાપો(f"{સંખ્યા}! = {પરિણામ}")

    # while લૂપ દર્શાવો
    ગણતરી = 0
    જ્યાંસુધી ગણતરી < 3:
        છાપો(f"ગણતરી: {ગણતરી}")
        ગણતરી += 1

    # try/except દર્શાવો
    પ્રયાસ:
        ક્રમગુણિત(-1)
    સિવાય મૂલ્યભૂલ તરીકે ભૂલ:
        છાપો(f"ભૂલ: {ભૂલ}")
    અંતે:
        છાપો("પૂર્ણ!")

જો __name__ == "__main__":
    મુખ્ય()
```

## Usage

```python
from legesher_i18n import LanguagePackLoader

# Load Gujarati pack for Python 3.12
loader = LanguagePackLoader()
pack = loader.load("gu", "python", "3.12")

# Translate code
from legesher import translate
english_code = translate(your_gu_code, from_lang="gu", to_lang="en")
```

## Contributing

Found a better translation? We welcome contributions from native speakers!

1. Edit `legesher_i18n_python_gu/packs/<version>.yml` for the Python version where the term was introduced:
   - `3.10.yml` - Base translations (most terms)
   - `3.11.yml` - Terms added in Python 3.11 (e.g., `except*`)
   - `3.12.yml` - Terms added in Python 3.12 (e.g., `type`)
   - `3.13.yml` / `3.14.yml` - Future additions
2. Submit a pull request with your reasoning
3. Translations should be natural, commonly used in CS education, and easy to type
