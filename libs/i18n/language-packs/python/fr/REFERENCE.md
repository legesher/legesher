## Reserved Words (2 terms)

Python conventions like `self` and `cls` translated deterministically by the
language pack rather than the LLM. Distinct from keywords because they aren't
actual reserved words in the Python language. (CORE-710)

| English | French |
| ------- | ------ |
| `cls` | `soiclasse` |
| `self` | `soi` |

## Example Code

Here's an example showing French Python code with Legesher:

```python
# Exemple: Fonction factorielle avec gestion des erreurs

de typing importer Optional

défini factorielle(n):
    """Calculer la factorielle de n."""
    si n < 0:
        élever valeurincorrecte("Les nombres négatifs ne sont pas autorisés")
    sinonsi n == 0 ou n == 1:
        retourner 1
    autre:
        retourner n * factorielle(n - 1)

défini principal():
    nombres = [entier(x) pour x dans plage(6)]

    pour nombre dans nombres:
        resultat = factorielle(nombre)
        imprimer(f"{nombre}! = {resultat}")

    # Démontrer la boucle while
    compteur = 0
    tant_que compteur < 3:
        imprimer(f"Compteur: {compteur}")
        compteur += 1

    # Démontrer try/except
    essayer:
        factorielle(-1)
    sauf valeurincorrecte comme erreur:
        imprimer(f"Erreur: {erreur}")
    enfin:
        imprimer("Terminé!")

si __name__ == "__main__":
    principal()
```

## Usage

```python
from legesher_i18n import LanguagePackLoader

# Load French pack for Python 3.12
loader = LanguagePackLoader()
pack = loader.load("fr", "python", "3.12")

# Translate code
from legesher import translate
english_code = translate(your_fr_code, from_lang="fr", to_lang="en")
```

## Contributing

Found a better translation? We welcome contributions from native speakers!

1. Edit `legesher_i18n_python_fr/packs/<version>.yml` for the Python version where the term was introduced:
   - `3.10.yml` - Base translations (most terms)
   - `3.11.yml` - Terms added in Python 3.11 (e.g., `except*`)
   - `3.12.yml` - Terms added in Python 3.12 (e.g., `type`)
   - `3.13.yml` / `3.14.yml` - Future additions
2. Submit a pull request with your reasoning
3. Translations should be natural, commonly used in CS education, and easy to type
