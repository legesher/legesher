## Example Code

Here's an example showing Greek Python code with Legesher:

```python
# Παράδειγμα: Συνάρτηση παραγοντικού με χειρισμό σφαλμάτων

από typing εισαγωγή Optional

δε παραγοντικό(n):
    """Υπολογισμός παραγοντικού του n."""
    αν n < 0:
        ανυψώστε ValueError("Οι αρνητικοί αριθμοί δεν επιτρέπονται")
    αν n == 0 ή n == 1:
        επιστροφή 1
    αλλιώς:
        επιστροφή n * παραγοντικό(n - 1)

δε κύριο():
    αριθμοί = [int(x) για x εν διαστήμα(6)]

    για αριθμός εν αριθμοί:
        αποτέλεσμα = παραγοντικό(αριθμός)
        εκτύπωση(f"{αριθμός}! = {αποτέλεσμα}")

    # Επίδειξη βρόχου while
    μετρητής = 0
    ενώ μετρητής < 3:
        εκτύπωση(f"Μετρητής: {μετρητής}")
        μετρητής += 1

    # Επίδειξη try/except
    προσπάθεια:
        παραγοντικό(-1)
    εκτός ValueError ως σφάλμα:
        εκτύπωση(f"Σφάλμα: {σφάλμα}")
    τελικά:
        εκτύπωση("Ολοκληρώθηκε!")

αν __name__ == "__main__":
    κύριο()
```

## Usage

```python
from legesher_i18n import LanguagePackLoader

# Load Greek pack for Python 3.12
loader = LanguagePackLoader()
pack = loader.load("el", "python", "3.12")

# Translate code
from legesher import translate
english_code = translate(your_el_code, from_lang="el", to_lang="en")
```

## Contributing

Found a better translation? We welcome contributions from native speakers!

1. Edit `legesher_i18n_python_el/packs/<version>.yml` for the Python version where the term was introduced:
   - `3.10.yml` - Base translations (most terms)
   - `3.11.yml` - Terms added in Python 3.11 (e.g., `except*`)
   - `3.12.yml` - Terms added in Python 3.12 (e.g., `type`)
   - `3.13.yml` / `3.14.yml` - Future additions
2. Submit a pull request with your reasoning
3. Translations should be natural, commonly used in CS education, and easy to type
