## Reserved Words (2 terms)

Python conventions like `self` and `cls` translated deterministically by the
language pack rather than the LLM. Distinct from keywords because they aren't
actual reserved words in the Python language. (CORE-710)

| English | Indonesian |
| ------- | ------ |
| `cls` | `kelasnya` |
| `self` | `diri` |

## Example Code

Here's an example showing Indonesian Python code with Legesher:

```python
# Contoh: Fungsi faktorial dengan penanganan kesalahan

dari typing mengimpor Optional

definisi faktorial(n):
    """Hitung faktorial dari n."""
    jika n < 0:
        meningkatkan Kesalahannilai("Angka negatif tidak diperbolehkan")
    jika_lain n == 0 atau n == 1:
        mengembalikan 1
    lainnya:
        mengembalikan n * faktorial(n - 1)

definisi utama():
    angka = [bilanganbulat(x) untuk x ada rentang(6)]

    untuk nomor ada angka:
        hasil = faktorial(nomor)
        cetak(f"{nomor}! = {hasil}")

    # Demonstrasi perulangan while
    hitungan = 0
    selama hitungan < 3:
        cetak(f"Hitungan: {hitungan}")
        hitungan += 1

    # Demonstrasi try/except
    coba:
        faktorial(-1)
    kecuali Kesalahannilai sebagai kesalahan:
        cetak(f"Kesalahan: {kesalahan}")
    akhirnya:
        cetak("Selesai!")

jika __name__ == "__main__":
    utama()
```

## Usage

```python
from legesher_i18n import LanguagePackLoader

# Load Indonesian pack for Python 3.12
loader = LanguagePackLoader()
pack = loader.load("id", "python", "3.12")

# Translate code
from legesher import translate
english_code = translate(your_id_code, from_lang="id", to_lang="en")
```

## Contributing

Found a better translation? We welcome contributions from native speakers!

1. Edit `legesher_i18n_python_id/packs/<version>.yml` for the Python version where the term was introduced:
   - `3.10.yml` - Base translations (most terms)
   - `3.11.yml` - Terms added in Python 3.11 (e.g., `except*`)
   - `3.12.yml` - Terms added in Python 3.12 (e.g., `type`)
   - `3.13.yml` / `3.14.yml` - Future additions
2. Submit a pull request with your reasoning
3. Translations should be natural, commonly used in CS education, and easy to type
