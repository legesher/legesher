## 0.1.0 (2025-01-06)

### Added

- Initial release of legesher-i18n
- Version-aware language pack system
- LanguagePackLoader with version awareness
- Language pack inheritance chains
- PythonVersionDetector for automatic version detection
- Python version detection and compatibility
- VersionIndex for managing pack compatibility
- Schema validation for language packs
- SchemaValidator for pack validation
- Comprehensive error handling for pack operations
