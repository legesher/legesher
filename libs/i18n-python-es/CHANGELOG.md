## 0.0.1 (2025-01-06)

### Added

- Initial release of Spanish language pack for Python
- Complete translations for Python 3.10-3.13
- Keywords: definir, clase, retornar, si, mientras, para, etc.
- Built-ins: imprimir, longitud, rango, lista, diccionario, etc.
- Logical operators: y, o, no
- Constants: Verdadero, Falso, Ninguno
- Version-aware pack system with inheritance
- Support for all Python 3.10+ keywords including match/case, except*, type
