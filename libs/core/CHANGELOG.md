## 0.1.0 (2025-01-06)

### Added

- Initial release of legesher-core
- Token-based translation engine for Python
- TokenTranslator for multilingual Python translation
- Cultural comment support (MLCP protocol)
- CulturalCommentParser and provider for IDE integration
- Git integration and translation tracking
- TranslationTracker for git metadata management
- AST transformation capabilities
- Comprehensive exception handling
