## 0.0.1 (2025-01-06)

### Added

- Initial release of Arabic language pack for Python
- Complete translations for Python 3.10-3.13
- Keywords: تعريف, صنف, إرجاع, إذا, بينما, لـ, etc.
- Built-ins: طباعة, طول, نطاق, قائمة, قاموس, etc.
- Logical operators: و, أو, ليس
- Constants: صحيح, خطأ, لاشيء
- Right-to-left (RTL) text support
- Version-aware pack system with inheritance
- Support for all Python 3.10+ keywords including match/case, except*, type
