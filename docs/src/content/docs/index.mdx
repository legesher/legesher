## What is Legesher?

Programming languages are predominately in English: `def`, `print`, `if`, `return`. That means millions of developers worldwide must learn English before they can learn to code.

Legesher changes the foundation of programming. Write Python in your own language: `definir` instead of `def`, `imprimir` instead of `print`, `si` instead of `if`, and innovate without ideas getting lost in translation. Your multilingual code runs as standard Python, integrates with git, and collaborates seamlessly with teammates coding in other natural languages.

## How It Works

<CardGrid>
	<Card title="Write in your language" icon="pencil">
		Install the VS Code extension, pick your language, and start coding. Legesher provides autocomplete, hover documentation, and diagnostics, all in your native language.
	</Card>
	<Card title="Collaborate across languages" icon="open-book">
		Code is stored in the language it was written in. A teammate who reads another language renders a copy with `legesher translate`; rendering a copy never changes the stored file.
	</Card>

## 52 Languages Supported

Legesher translates Python keywords, builtins, and exceptions into 52 languages. All language packs are in experimental status. Translations work and are ready to use, with community validation underway.
