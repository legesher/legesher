## What is Legesher?

Programming languages are predominately in English: `def`, `print`, `if`, `return`. That means millions of developers worldwide must learn English before they can learn to code.

Legesher changes the foundation of programming. Write Python in your own language: `definir` instead of `def`, `imprimir` instead of `print`, `si` instead of `if`, and innovate without ideas getting lost in translation. Your multilingual code runs as standard Python, integrates with git, and collaborates seamlessly with teammates coding in other natural languages.

## 26 Languages Supported

Legesher translates Python keywords, builtins, and exceptions into 26 languages. All language packs are in experimental status. Translations work and are ready to use, with community validation underway.

العربية (Arabic) · 中文 (Chinese) · Dansk (Danish) · Nederlands (Dutch) · English · Suomi (Finnish) · Français (French) · Deutsch (German) · Ελληνικά (Greek) · עברית (Hebrew) · हिन्दी (Hindi) · Magyar (Hungarian) · Bahasa Indonesia (Indonesian) · Italiano (Italian) · 日本語 (Japanese) · 한국어 (Korean) · Bahasa Melayu (Malay) · Norsk (Norwegian) · Polski (Polish) · Português (Portuguese) · Русский (Russian) · Español (Spanish) · Svenska (Swedish) · ไทย (Thai) · Türkçe (Turkish) · Tiếng Việt (Vietnamese)
