## Overview

Legesher is a collection of developer tools and packages that enable developers to code in their native language instead of English. From creation within an IDE to collaboration across projects and git histories, Legesher's tools remove English as the prerequisite of coding.

## Architecture Highlights

### Multilingual Code Protocol (MLCP)

A standardized protocol that enables:
- Language pack discovery and distribution
- Code translation between natural languages
- IDE and tooling integration
- Community-driven translation validation

### Version-Aware Language Packs

Support for multiple Python versions (3.10+) with automatic adaptation:
- Pack inheritance system
- Auto-detection of Python version
- Compatibility tracking
- Auto-update on new releases

### Git Integration

Seamless version control with multilingual code:
- Canonical English storage
- Developer-specific language views
- Dual-language commit messages
- Translation metadata tracking

### Language Server Protocol

IDE-agnostic support via LSP:
- Works with VS Code, Cursor, Windsurf, Zed, PyCharm
- Real-time translation
- Localized IntelliSense
- Cultural context annotations
