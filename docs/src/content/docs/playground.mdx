Edit the localized Python below and press **Run** (or `Cmd`/`Ctrl` + `Enter`). Legesher
translates the keywords and built-ins to English and executes the result — entirely in
your browser, with nothing sent to a server.

The first run downloads the Python runtime (about 6 MB) and the translation engine; your
browser caches them, so later runs start quickly.

<Playground />

Pick a language from the selector, or a sample from the ladder next to it — six programs
from hello world up to async/await, each translated into the selected language. **Show
English** flips the buffer to Python's own keywords and back without losing your edits, and
**Copy link** turns the current code, language, and sample into a shareable URL. Editing
is left-to-right only for now — right-to-left languages will follow.
