Edit the localized Python below and press **Run** (or `Cmd`/`Ctrl` + `Enter`). Legesher
translates the keywords and built-ins to English and executes the result — entirely in
your browser, with nothing sent to a server.

The first run downloads the Python runtime (about 6 MB) and the translation engine; your
browser caches them, so later runs start quickly.

Pick a language from the selector to load its example. Editing is left-to-right only for
now — right-to-left languages will follow.
