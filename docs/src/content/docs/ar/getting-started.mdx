## البدء السريع

### 1. ثبّت امتداد VS Code

ثبّته من VS Code Marketplace:

- افتح لوحة الامتدادات (**Cmd+Shift+X** على macOS، و**Ctrl+Shift+X** على Windows وLinux)
- ابحث عن **Legesher**
- انقر على **Install**

أو ثبّته يدويًا:

```bash
code --install-extension legesher.legesher-vscode
```

{/* VISUAL: Screenshot of VS Code marketplace showing the Legesher extension */}

### 2. اختر لغتك

يُفتح دليل **Get Started with Legesher** بعد تثبيت الامتداد، أو عند فتح ملف Python لأول مرة. في
خطوة **Choose Your Target Language**، انقر على **Select Language** واختر لغتك.

أو يدويًا:

1. افتح لوحة الأوامر (**Cmd+Shift+P** على macOS، و**Ctrl+Shift+P** على Windows وLinux)
2. اكتب **Legesher: Select Language** ثم اضغط **Enter**
3. اختر لغتك من القائمة

{/* VISUAL: [Demo 7] GIF/screenshot of the language selector dropdown in command palette */}

### 3. ابدأ البرمجة

افتح ملف Python وابدأ الكتابة! سيقوم Legesher بما يلي:

- اقتراح الكلمات المفتاحية بلغتك
- عرض وثائق التحويم بلغتك
- ترجمة الدوال المضمنة والاستثناءات في Python
- دعم IntelliSense بلغتك الأم

{/* VISUAL: [Demo 10] GIF of autocomplete suggesting translated keywords in action */}

## اللغات المدعومة

يدعم Legesher حاليًا Python 3.10 وما بعده مع ترجمات إلى **56 لغة**، من الأمهرية (አማርኛ) إلى
الخوسية (isiXhosa)، ومنها لغات تُكتب من اليمين إلى اليسار مثل العربية والعبرية (עברית) والفارسية
(فارسی) والأردية (اردو).

راجع [اللغات المدعومة](/ar/reference/supported-languages/) للاطلاع على القائمة الكاملة.

## الميزات

### ترجمة الكلمات المفتاحية

اكتب الكلمات المفتاحية في Python بلغتك الأم:

```python

    mensaje = f"¡Hola, {nombre}! Bienvenido a Legesher."
    imprimir(mensaje)
    devolver mensaje

definir saludar_con_edad(nombre, edad):
    si edad < 18:
        categoria = "joven"
    si_no edad < 65:
        categoria = "adulto"
    sino:
        categoria = "sabio"
    imprimir(f"¡Hola, {categoria} {nombre}!")
    devolver categoria

definir ejemplo_manejo_errores():
    probar:
        resultado = 100 / entero(entrada("Número: "))
        imprimir(f"Resultado: {resultado}")
    excepto errordedivisiónporcero:
        imprimir("Error: No se puede dividir por cero.")
    excepto errordevalor:

    finalmente:
        imprimir("Operación completada.")
```

### التكامل مع git

يُخزَّن كودك في git باللغة التي كتبته بها:

- **ما تراه أنت:** الكود بلغتك الأم
- **التخزين في git:** لغة المؤلف، شكل مخزَّن واحد لكل ملف؛ وأي كلمة مفتاحية بلغة أخرى تتسلل إلى الملف تُعاد إلى لغته عند `git add`
- **شكل التنفيذ:** كلمات مفتاحية بالإنجليزية، تُنتَج فقط عند تشغيل الكود

{/* VISUAL: [Demo 15] Clean filter flow diagram: one stored form per file, stray-keyword normalization at git add, run form at run time */}

### دعم IntelliSense

احصل على الإكمال التلقائي ووثائق التحويم والتشخيصات بلغتك:

- اكتب `imprimir` وسترى اقتراحات لـ `print()`
- حوّم فوق الدوال لرؤية وثائق مترجمة
- رسائل الخطأ بلغتك

## الإعدادات

### القياس عن بُعد

تحكم في البيانات التي يجمعها Legesher:

**القياس الأساسي عن بُعد** (معطّل افتراضيًا):

```json
{
  "legesher.telemetry.enabled": false
}
```

**المساهمة في تدريب نماذج تعلم الآلة** (بموافقة صريحة فقط):

```json
{
  "legesher.telemetry.contributeToMLTraining": false
}
```

[اعرف المزيد عن الخصوصية](/ar/privacy/)

### اختيار اللغة

غيّر لغة البرمجة في أي وقت:

1. انقر على مؤشر اللغة في شريط الحالة (أسفل يمين النافذة)
2. أو استخدم لوحة الأوامر: **Legesher: Select Language**

## استكشاف الأخطاء وإصلاحها

### الامتداد لا يتفعّل؟

1. تأكد من أن Python مثبت لديك
2. افتح ملف `.py` لتشغيل التفعيل
3. راجع لوحة الإخراج: **View** > **Output** ثم اختر **Legesher Language Server** من القائمة المنسدلة
   في اللوحة

### الترجمات لا تظهر؟

1. تحقق من اختيار اللغة: راجع شريط الحالة
2. أعد تشغيل خادم اللغة: لوحة الأوامر > **Legesher: Restart Language Server**
3. ابحث عن الأخطاء في لوحة **Output**
