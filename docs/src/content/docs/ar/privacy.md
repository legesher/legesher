## امتداد VS Code

### المعالجة المحلية

تتم معالجة كودك المصدري بالكامل **محليًا على جهازك**. لا نرسل كودك أبدًا إلى خوادمنا
ولا إلى أي خدمات من أطراف خارجية. كل الترجمة ومرشحات git وميزات IntelliSense تعمل
دون اتصال بالإنترنت بنسبة 100%.

### القياس الأساسي عن بُعد (اختياري)

عند تفعيله، نجمع إحصاءات استخدام مجهولة الهوية لمساعدتنا على تحسين المنتج:

- أحداث تفعيل الامتداد
- تكرار استخدام الميزات (الأوامر التي تستخدمها)
- استخدام حزم اللغات (اللغات التي تترجم إليها ومنها)
- مقاييس أداء الامتداد (زمن بدء التشغيل، سرعة الاستجابة)
- تقارير الأخطاء (تقارير الأعطال ورسائل الخطأ — دون أي محتوى من الكود)

**ما لا نجمعه:**

- ❌ كودك المصدري أو محتويات ملفاتك
- ❌ معلومات التعريف الشخصية (الاسم، البريد الإلكتروني، عنوان IP)
- ❌ أسماء المشاريع أو مسارات الملفات
- ❌ أسماء المتغيرات أو الدوال التي يعرّفها المستخدم
- ❌ القيم الحرفية من كودك
- ❌ أي بيانات حساسة من أي نوع

**التحكم:** يمكنك تعطيل القياس عن بُعد في أي وقت من إعدادات VS Code:

```json
{
  "legesher.telemetry.enabled": false
}
```

### بيانات تدريب نماذج تعلم الآلة (بموافقة صريحة فقط)

يمكنك اختياريًا المساعدة في تحسين نماذج الترجمة في Legesher من خلال مشاركة ملاحظات مجهولة الهوية عندما
تعدّل اقتراحات الترجمة التي نقدمها.

#### ما نجمعه

- **تصحيحات الترجمة**: عندما تغيّر اقتراحًا من Legesher (مثل "media" ← "promedio")
- **سياق الكود**: البنية عالية المستوى (دالة، متغير، صنف)
- **نوع العملية**: تصنيف أساسي (عمليات حسابية، معالجة سلاسل نصية، إلخ)

#### كيف تُستخدم

تساعدنا هذه البيانات على:

1. تحسين دقة الترجمة للغتك
2. فهم كيفية تعامل الناطقين الأصليين مع مسائل البرمجة
3. تحديد الأنماط الثقافية واللغوية في البرمجة

#### التحكم

- **الإعداد:** `legesher.telemetry.contributeToMLTraining`
- **القيمة الافتراضية:** `false` (يجب أن توافق صراحةً)
- **غيّره في أي وقت:** إعدادات VS Code ← ابحث عن "Legesher ML Training"

### تخزين بيانات القياس عن بُعد

- **الموقع:** Azure Application Insights (منطقة الولايات المتحدة)
- **الاحتفاظ:** 90 يومًا لبيانات القياس عن بُعد؛ بيانات تدريب تعلم الآلة مجهولة الهوية تُحفظ إلى أجل غير مسمى
- **الأمان:** تشفير وفق معايير الصناعة (TLS 1.3 أثناء النقل، وAES-256 أثناء التخزين)

### القياس عن بُعد الخاص بـ VS Code

يجمع VS Code نفسه بيانات قياس عن بُعد بشكل مستقل عن Legesher. راجع
[بيان خصوصية VS Code](https://code.visualstudio.com/docs/supporting/faq#_microsoft-privacy-statement)
وإعدادات القياس عن بُعد في VS Code.

## موقع الوثائق (docs.legesher.io)

### الاستضافة

يُستضاف موقع الوثائق هذا على [Vercel](https://vercel.com). يعالج Vercel سجلات الوصول القياسية
للخادم (عناوين IP، وأوقات الطلبات، وعناوين URL) كجزء من عمليات الاستضافة الاعتيادية. راجع
[سياسة خصوصية Vercel](https://vercel.com/legal/privacy-policy) للتفاصيل.

### التحليلات

يستخدم هذا الموقع [Vercel Web Analytics](https://vercel.com/docs/analytics/privacy-policy)، وهو مصمم
لاحترام الخصوصية:

- **بدون ملفات تعريف ارتباط:** لا يستخدم Vercel Web Analytics ملفات تعريف الارتباط ولا أي تخزين من جهة العميل
- **بدون معرّفات شخصية:** يُحدَّد الزوار عبر تجزئة (hash) مجهولة لا يمكن استخدامها
  لتتبع الأفراد عبر المواقع
- **بدون تتبع عبر المواقع:** لا يمكن للبيانات إعادة بناء جلسات التصفح ولا تحديد هوية مستخدمين بعينهم
- **بيانات مجمعة فقط:** نرى أعداد مشاهدات الصفحات والمصادر المحيلة والموقع الجغرافي (على مستوى الدولة/المنطقة)
  ونوع الجهاز والمتصفح، وكلها بشكل مجمع

البيانات المجموعة لكل مشاهدة صفحة: عنوان URL، والمصدر المحيل، والموقع الجغرافي (الدولة/المنطقة)، ونظام تشغيل
الجهاز، والمتصفح، ونوع الجهاز، والوقت. لا تُخزَّن عناوين IP ولا وكلاء المستخدم ولا أي معلومات شخصية.

ولأن Vercel Web Analytics لا يجمع بيانات شخصية ولا يستخدم ملفات تعريف الارتباط، لا يلزم عرض أي إشعار موافقة
بموجب GDPR أو لوائح ePrivacy.

### الخطوط

جميع الخطوط (Noto Sans) مستضافة ذاتيًا وتُقدَّم مباشرة من `docs.legesher.io`. لا تُستخدم أي خدمات
خطوط من أطراف خارجية، وبالتالي لا تُشارَك أي بيانات مع مزودين خارجيين عند تحميل الصفحات.

## الامتثال لـ GDPR وCCPA

تنطبق حقوقك بموجب GDPR وGDPR البريطاني وCCPA/CPRA وقوانين الخصوصية الإقليمية الأخرى على كل من
بيانات القياس عن بُعد مجهولة الهوية وبيانات تدريب تعلم الآلة الخاضعة للموافقة الصريحة الموضحة أعلاه.
يمكنك على وجه الخصوص:

- **تعطيل كل بيانات القياس عن بُعد** في أي وقت من إعدادات VS Code (راجع ملاحظات _التحكم_ في كل
  قسم أعلاه) — وهي أسرع طريقة لإيقاف جمع البيانات كليًا
- **طلب الوصول إلى أي بيانات جمعناها أو تصحيحها أو حذفها**، عبر مراسلتنا على
  [privacy@legesher.com](mailto:privacy@legesher.com)
- **سحب الموافقة على تدريب تعلم الآلة** بإيقاف `legesher.telemetry.contributeToMLTraining`؛
  يتوقف الجمع المستقبلي فورًا، ويمكنك طلب حذف المساهمات المجهولة
  السابقة بمراسلتنا
- **تقديم شكوى** لدى سلطة حماية البيانات المحلية لديك (المنطقة الاقتصادية الأوروبية) أو لدى
  [Information Commissioner's Office](https://ico.org.uk/make-a-complaint/) (المملكة المتحدة) إذا كنت
  تعتقد أننا تعاملنا مع بياناتك بشكل غير سليم

القائمة الكاملة لحقوقك — بما فيها المواد 15–22 من GDPR، وفئات CCPA/CPRA، وقوانين الخصوصية
في الولايات (فيرجينيا، كولورادو، كونيتيكت، يوتا، نيفادا)، وأساس النقل الدولي للبيانات،
ومدد الاحتفاظ، ومن نحن (Legesher Inc وLegesher Global Tech Limited) — موجودة في
[سياسة الخصوصية العامة](https://www.legesher.io/privacy).
