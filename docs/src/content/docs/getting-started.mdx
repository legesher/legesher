## Quick Start

### 1. Install the VS Code Extension

Install from the VS Code Marketplace:

- Open the **Extensions** view (**Cmd+Shift+X** on macOS, **Ctrl+Shift+X** on Windows and Linux)
- Search for **Legesher**
- Click **Install**

Or install manually:

```bash
code --install-extension legesher.legesher-vscode
```

{/* VISUAL: Screenshot of VS Code marketplace showing the Legesher extension */}

Hover, completion, diagnostics and keyword highlighting come from a separate
language server: the `legesher-lsp` command, from the `legesher-language-server`
Python package. Install it with a tool installer, so that `legesher-lsp` works
outside any project environment:

```bash
pipx install legesher-language-server
```

Or, with uv:

```bash
uv tool install legesher-language-server
```

If the installer warns that its bin directory is not on your `PATH`, run
`pipx ensurepath` or `uv tool update-shell`, then restart VS Code.

The extension starts without the server, and the **Legesher** item in the status
bar then shows a warning that names the package. `legesher-lsp` has to be on
the `PATH` VS Code sees, or the `legesher.serverCommand` setting has to hold its
full path.

### 2. Select Your Language

The **Get Started with Legesher** walkthrough opens after you install the extension, or
the first time you open a Python file. In its **Choose Your Target Language** step, click
**Select Language** and choose your language.

Or manually:

1. Open the Command Palette (**Cmd+Shift+P** on macOS, **Ctrl+Shift+P** on Windows and Linux)
2. Type **Legesher: Select Language** and press **Enter**
3. Choose your language from the list

{/* VISUAL: [Demo 7] GIF/screenshot of the language selector dropdown in command palette */}

### 3. Start Coding

Open a Python file and start typing! Legesher will:

- Provide keyword suggestions in your language
- Show hover documentation in your language
- Translate Python builtins and exceptions
- Support IntelliSense in your native language

## Supported Languages

Legesher supports Python 3.10+ in **56 languages**, from Amharic (አማርኛ) to Xhosa
(isiXhosa), including right-to-left languages such as Arabic (العربية), Hebrew (עברית),
Persian (فارسی) and Urdu (اردو).

See [Supported Languages](/reference/supported-languages/) for the full list.

## Features

### Keyword Translation

Write Python keywords in your native language:

```python
# Spanish example: keywords, control flow, and error handling
definir saludar(nombre):
    mensaje = f"¡Hola, {nombre}! Bienvenido a Legesher."
    imprimir(mensaje)
    devolver mensaje

definir saludar_con_edad(nombre, edad):
    si edad < 18:
        categoria = "joven"
    si_no edad < 65:
        categoria = "adulto"
    sino:
        categoria = "sabio"
    imprimir(f"¡Hola, {categoria} {nombre}!")
    devolver categoria

definir ejemplo_manejo_errores():
    probar:
        resultado = 100 / entero(entrada("Número: "))
        imprimir(f"Resultado: {resultado}")
    excepto errordedivisiónporcero:
        imprimir("Error: No se puede dividir por cero.")
    excepto errordevalor:
        imprimir("Error: Ingresa un número válido.")
    finalmente:
        imprimir("Operación completada.")
```

### Git Integration

Your code is stored in git in the language you wrote it in:

- **Your view:** Code in your native language
- **Git storage:** The author's language, one stored form per file; a stray keyword in another language is
  normalized when the file is staged
- **Run form:** English keywords, produced only when the code runs

{/* VISUAL: [Demo 15] Clean filter flow diagram: one stored form per file, stray-keyword normalization at git add, run form at run time */}

### IntelliSense Support

Get completions, hover docs, and diagnostics in your language:

- Type `imprimir` and see suggestions for `print()`
- Hover over functions to see localized documentation
- Error messages in your language

## Settings

### Telemetry

Control what data Legesher collects:

**Basic telemetry** (disabled by default):

```json
{
  "legesher.telemetry.enabled": false
}
```

**ML training contributions** (opt-in only):

```json
{
  "legesher.telemetry.contributeToMLTraining": false
}
```

[Learn more about privacy](/privacy/)

### Language Selection

Change your coding language anytime:

1. Click the language indicator in the status bar (bottom right)
2. Or use the Command Palette: **Legesher: Select Language**

## Troubleshooting

### Extension not activating?

1. Check that you have Python installed
2. Open a `.py` file to trigger activation
3. Check the Output panel: **View** > **Output**, then choose **Legesher Language Server** in the
   panel's dropdown

### Translations not showing?

1. Hover over the **Legesher** item in the status bar. If it shows a warning, the
   language server was not found, and the tooltip names the package it needs
2. Verify language selection: Check status bar
3. Restart the language server: Command Palette > **Legesher: Restart Language Server**
4. Check for errors in the **Output** panel
