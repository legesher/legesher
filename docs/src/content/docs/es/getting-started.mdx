## Inicio rápido

### 1. Instala la extensión de VS Code

Instálala desde el VS Code Marketplace:

- Busca "Legesher" en el panel de extensiones
- Haz clic en "Install"

O instálala manualmente:

```bash
code --install-extension legesher.legesher-vscode
```

{/* VISUAL: Screenshot of VS Code marketplace showing the Legesher extension */}

### 2. Selecciona tu idioma

Después de la instalación verás un cuadro de diálogo de bienvenida. Haz clic en **"Choose Your Language"** para seleccionar el idioma en el que quieres programar.

O hazlo manualmente:

1. Abre la paleta de comandos (Cmd+Shift+P o Ctrl+Shift+P)
2. Escribe "Legesher: Select Language"
3. Elige tu idioma de la lista

{/* VISUAL: [Demo 7] GIF/screenshot of the language selector dropdown in command palette */}

### 3. Empieza a programar

Abre un archivo de Python y empieza a escribir. Legesher hará lo siguiente:

- Sugerir palabras clave en tu idioma
- Mostrar documentación al pasar el cursor en tu idioma
- Traducir las funciones integradas y las excepciones de Python
- Ofrecer IntelliSense en tu idioma nativo

## Funcionalidades

### Traducción de palabras clave

Escribe las palabras clave de Python en tu idioma nativo:

```python
# Spanish example: keywords, control flow, and error handling
definir saludar(nombre):
    mensaje = f"¡Hola, {nombre}! Bienvenido a Legesher."
    imprimir(mensaje)
    devolver mensaje

definir saludar_con_edad(nombre, edad):
    si edad < 18:
        categoria = "joven"
    si_no edad < 65:
        categoria = "adulto"
    sino:
        categoria = "sabio"
    imprimir(f"¡Hola, {categoria} {nombre}!")
    devolver categoria

definir ejemplo_manejo_errores():
    probar:
        resultado = 100 / entero(entrada("Número: "))
        imprimir(f"Resultado: {resultado}")
    excepto errordedivisiónporcero:
        imprimir("Error: No se puede dividir por cero.")
    excepto errordevalor:
        imprimir("Error: Ingresa un número válido.")
    finalmente:
        imprimir("Operación completada.")
```

### Integración con git

Tu código se guarda en inglés en git, pero tú lo ves en tu idioma:

- **Tu vista:** código en tu idioma nativo
- **Almacenamiento en git:** inglés (para la colaboración universal)
- **Traducción automática:** en ambas direcciones, sin fricciones

### Compatibilidad con IntelliSense

Recibe autocompletado, documentación al pasar el cursor y diagnósticos en tu idioma:

- Escribe `imprimir` y verás sugerencias para `print()`
- Pasa el cursor sobre las funciones para ver documentación localizada
- Mensajes de error en tu idioma

## Configuración

### Telemetría

Controla qué datos recopila Legesher:

**Telemetría básica** (desactivada de forma predeterminada):

```json
{
  "legesher.telemetry.enabled": false
}
```

**Contribuciones al entrenamiento de ML** (solo con consentimiento explícito):

```json
{
  "legesher.telemetry.contributeToMLTraining": false
}
```

[Más información sobre privacidad](/es/privacy/)

### Selección de idioma

Cambia tu idioma de programación en cualquier momento:

1. Haz clic en el indicador de idioma de la barra de estado (abajo a la derecha)
2. O usa la paleta de comandos: "Legesher: Select Language"

## Solución de problemas

### ¿La extensión no se activa?

1. Comprueba que tienes Python instalado
2. Abre un archivo `.py` para activar la extensión
3. Revisa el panel de salida: View > Output > selecciona "Legesher Language Server"

### ¿No aparecen las traducciones?

1. Verifica la selección de idioma: revisa la barra de estado
2. Reinicia el servidor de lenguaje: paleta de comandos > "Legesher: Restart Language Server"
3. Busca errores en el panel de salida
